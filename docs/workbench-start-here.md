# MoonReconcile 本机工作台

1. 解压整个 `moonreconcile-workbench-0.2.0.zip`，保留解压出的文件夹结构。
2. 安装并使用 Node.js 22 或更高版本。
3. 在该文件夹内运行：

   ```sh
   node workbench/start.mjs
   ```

4. 只在本机浏览器打开终端显示的 `http://127.0.0.1:.../#token=...` 地址。不要把含令牌的地址发给别人。
5. 完成后在启动终端按 `Ctrl+C`。正常退出会关闭本机服务并清理本次拥有的暂存目录；下载到其他位置的 ZIP 文件由你保管。

本工作台只监听 `127.0.0.1`。它处理你选入的 CSV、配置和复核文件，不会自动打开浏览器，也不要求安装 MoonBit、npm 或 Python。运行包已带预编译 MoonBit 引擎和固定生产依赖。浏览器只访问本机服务。

首次使用可从页面的 `orders` 合成示例开始。示例是人工编写的测试材料，不是客户资料或效果证明。当前 Phase A 候选默认公开入口支持 CSV 导入、Config v1 表单、比较、人工复核、决定回导、报告导出和完整运行 ZIP 的校验恢复。受限 XLSX 代码要求显式选择可见工作表、矩形范围及每列模式，拒绝公式并保留隐藏/筛选行警告；它仍等待同一离线包的完整验收与后续激活，因此本指南不把它列为已交付入口。恢复会在本机重新运行原核心并比对报告字节。

浏览器关闭或终端异常退出后，系统临时目录中可能留下以 `moonreconcile-` 开头的本次会话目录。删除前先确认没有仍在运行的工作台进程，并确认目录中 `.owner` 标记属于本次遗留会话。不要删除其他程序的临时目录。

进一步说明见 [工作台使用与范围](workbench.md)、[命令行帮助](../cli/main.mjs) 与 [限制记录](limitations.md)。
